About This Template

This example demonstrates the structure of an HTML5 document with semantic tags, images, and links.

Topics Covered

HTML Structure

Learn how tags form the building blocks of web pages. For more details, visit Google.

Semantic Tags

Understand how elements like <header>, <section>, and <footer> improve meaning and accessibility.

Explanation of HTML5 Tags Used

This table summarizes all the HTML5 elements used in this educational template, including their purpose and common attributes.

Tag Example / Attribute Purpose / Explanation
<!DOCTYPE html> HTML5 declaration Ensures browser renders in standards mode
<html lang="en"> Language attribute set to English Root of the HTML document
<head> Contains metadata, not visible on the page
<meta charset="UTF-8"> Specifies Unicode encoding for all languages
<meta name="viewport"> content="width=device-width, initial-scale=1.0" Makes page responsive on all screen sizes
<meta name="description"> content="..." Provides short SEO-friendly summary of the page
<title> HTML5 Educational Template Displayed in browser tab
<link rel="stylesheet"> href="styles.css" Links an external CSS file
<script> src="script.js" defer Links JavaScript file, defers execution until loaded
<body> Contains all visible content on the page
<header> Introductory content such as logo or navigation
<h1>...</h1> Top-level heading for the page
<nav> Defines navigation links for the site
<ul>, <li> List of navigation items Represents unordered list of links or items
<a href="#about"> Internal link Scrolls to an element on the same page
<a href="https://www.google.com" target="_blank"> External link Opens Google in a new browser tab
<a href="mailto:info@example.com"> Email link Opens the user’s email client
<main> Holds the main, unique content of the page
<section> Groups related thematic content
<article> Independent, self-contained content block
<h2>, <h3> Subheadings that provide hierarchy and structure
<p> Paragraph element for text content
<figure> Groups visual content like images with captions
<img> src="Hierarchy.png" alt="HTML5 hierarchy diagram" Displays image from local folder; alt provides accessibility text
<figcaption> Adds a descriptive caption to a figure
<aside> Sidebar or supplementary information
<footer> Bottom section with author info or contact links
&copy; HTML entity Displays the © copyright symbol

Did You Know?

The <main> tag can only appear once per page!
